# epoch3-coffeescript-app

This repository contains files for writing an app in coffeescript for
[Constellation-epoch3](/ThatBeaverDev/Constellation-epoch3).

To get started, fork this repository and clone it. You can then run
`install.sh`, edit the coffeescript code and run `build.sh` to product your app
in `./dist/app.js`. This file can be ran in Constellation.
